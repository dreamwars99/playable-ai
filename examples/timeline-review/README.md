# Timeline Review Example

A lightweight event timeline review demo.

It shows the Playable AI contract:

```text
timeline state -> task pack -> mock provider -> candidate cards -> apply / ignore
```

This is a generic creative planning example. It reviews continuity, pacing, and missing bridge events without generating long-form prose or taking ownership of the user's timeline.

Run it:

```bash
pnpm --filter @playable-ai/example-timeline-review dev
```
