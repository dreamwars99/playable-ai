# Code of Conduct

Playable AI welcomes contributors who want safer, more inspectable AI workflows for open-source apps.

## Expected Behavior

- Be kind and specific in issues, discussions, and pull requests.
- Explain tradeoffs when proposing changes to core contracts.
- Respect maintainers' time by keeping examples isolated and reproducible.
- Keep safety boundaries clear: model output should produce reviewable candidates, not unreviewed writes.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Posting secrets, private data, or credentials.
- Using this project to build real-world surveillance, weapon targeting, or operational harm workflows.
- Pressuring maintainers to merge unsafe provider, auth, or state-mutation behavior.

## Enforcement

Maintainers may edit, close, or remove issues and pull requests that violate this code of conduct. Repeated violations may result in blocking from the project.
