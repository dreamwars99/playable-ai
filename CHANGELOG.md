- Add the `@playable-ai/react` package with task, candidate queue, and provider runner hooks.

- Add public docs for concepts, integration, provider safety, repository structure, application notes, and AI-agent customization.
- Add community maintenance files for security, conduct, issue templates, and application notes.
- Add GitHub Actions checks for typecheck, tests, and builds.
